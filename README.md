## 🧠 About the Project

**Dart CrossWords Game** is an educational crossword game created to help learners improve their knowledge of the Dart programming language.

Instead of simply memorizing syntax, players must solve clues, recognize programming concepts, and complete a crossword grid using their knowledge of Dart.

From fundamental concepts to advanced collections, every question is an opportunity to learn while having fun.

🎯 **The mission:** Make learning Dart more interactive, enjoyable, and challenging!

---

## ✨ Features

- 🧩 **Interactive Crossword Grid** — Solve programming clues directly in the game.
- 💻 **Dart Programming Questions** — Practice Dart syntax, types, methods, and collections.
- 📚 **Three Difficulty Levels** — Easy, Medium, and Hard.
- 🔍 **Interactive Hints** — Get help when you need it.
- ⏱️ **10-Minute Challenge** — Test your knowledge against the clock.
- ⚡ **Time Bonuses** — Earn extra time through correct answers, with balanced rewards.
- 🏆 **Score & Results** — Challenge yourself to complete the crossword successfully.
- 📱 **Responsive Design** — Enjoy the game on desktop and mobile devices.
- 🖱️ **Mouse & Touch Support** — Interact with the game using a mouse or touchscreen.
- 🌐 **Play Online** — Access the game directly through your browser.

## 📖 Topics Covered

### 🟢 Easy
- Dart data types and basic concepts
- Variables and keywords
- Strings and common properties
- Lists, Sets, and Maps

### 🟡 Medium
- Collection methods and conditions
- Functional operations on collections
- String manipulation
- Dart language concepts

### 🔴 Hard
- Hard Collection methods

The game contains **25 crossword questions** distributed across three difficulty levels:

| Difficulty | Number of Questions |
|---|---:|
| 🟢 Easy | 12 |
| 🟡 Medium | 10 |
| 🔴 Hard | 3 |
| **Total** | **25** |

## 🎮 How to Play

1. 🌐 Open Dart CrossWords Game in your browser.
2. 🧩 Select a crossword cell or word.
3. 🔍 Read the corresponding programming clue.
4. ⌨️ Enter your answer into the grid.
5. 💡 Use the available hints when necessary.
6. ⏱️ Manage your time wisely and take advantage of time bonuses.
7. 🏆 Complete the crossword before the timer reaches zero!

**Tip:** Pay attention to the number of letters required by each answer. A good understanding of Dart collections can help you solve the harder questions.
